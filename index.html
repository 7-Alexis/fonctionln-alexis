1. 📚 Introduction

La fonction logarithme népérien, notée ln, est une fonction très importante en mathématiques.

Elle est liée à la fonction exponentielle et intervient dans de nombreux problèmes de Terminale.

ln(e) = 1

2. 📖 Définition

La fonction logarithme népérien est définie sur l'ensemble des nombres réels strictement positifs.

Domaine de définition : ]0 ; +∞[

Pour tout réel x > 0, ln(x) est le nombre réel tel que :

eln(x) = x

3. 🔗 Relation avec la fonction exponentielle

Les fonctions exponentielle et logarithme népérien sont réciproques l'une de l'autre.

eln(x) = x    (x > 0)
ln(ex) = x

Ces deux relations sont fondamentales.

4. 🚨 Domaine de définition

On peut calculer ln(x) uniquement lorsque :

x > 0

Exemples

  • ln(2) ✅ existe
  • ln(0,5) ✅ existe
  • ln(1) ✅ existe
  • ln(0) ❌ n'existe pas
  • ln(-3) ❌ n'existe pas dans ℝ

5. 🧮 Propriétés du logarithme

Pour a > 0 et b > 0 :

ln(ab) = ln(a) + ln(b)
ln(a / b) = ln(a) − ln(b)
ln(an) = n ln(a)
ln(1 / a) = −ln(a)
ln(√a) = ½ ln(a)

⚠️ Attention

Il ne faut surtout pas écrire :

ln(a + b) = ln(a) + ln(b) ❌

Cette propriété est fausse.

6. ⭐ Valeurs remarquables

Expression Valeur
ln(1) 0
ln(e) 1
ln(e²) 2
ln(e³) 3
eln(x) x

7. ✏️ Dérivée

La fonction ln(x) est dérivable sur ]0 ; +∞[.

(ln x)' = 1 / x

Cas général

Si u est une fonction dérivable et u(x) > 0 :

[ln(u(x))]' = u'(x) / u(x)

Exemple

f(x) = ln(2x + 1)

On a :

f'(x) = 2 / (2x + 1)

8. 📉 Limites importantes

limx→0⁺ ln(x) = −∞
limx→+∞ ln(x) = +∞
limx→+∞ ln(x) / x = 0

Ces limites sont très utiles lors de l'étude des fonctions.

9. 📈 Variations de ln

Pour tout x > 0 :

(ln x)' = 1/x > 0

La dérivée est positive sur ]0 ; +∞[.

👉 ln est strictement croissante sur ]0 ; +∞[

12. 🧠 Équations logarithmiques

Pour résoudre une équation contenant ln, il faut toujours vérifier le domaine de définition.

Exemple 1

ln(x) = 2

On applique la fonction exponentielle :

x = e²

Exemple 2

ln(x) = ln(5)

Comme ln est strictement croissante :

x = 5

13. ⚖️ Inégalités logarithmiques

Comme la fonction ln est strictement croissante :

ln(a) < ln(b) ⇔ a < b

avec a > 0 et b > 0.

Exemple

ln(x) > ln(3)

Donc :

x > 3

14. 🔎 Étude d'une fonction contenant ln

Considérons :

f(x) = x ln(x)

Son domaine est :

Df = ]0 ; +∞[

Sa dérivée est :

f'(x) = ln(x) + 1

On peut ensuite étudier le signe de f'(x) afin de déterminer les variations de f.

16. 📝 Exercices

Exercice 1

Calculer :

A = ln(e³)
Correction :

ln(e³) = 3 ln(e) = 3.

Réponse : A = 3.

Exercice 2

Résoudre :

ln(x) = 4
Correction :

ln(x) = 4

Donc :

x = e⁴
Solution : x = e⁴.

Exercice 3

Simplifier :

ln(2) + ln(5)
Correction :

ln(2) + ln(5) = ln(2 × 5)

Donc :

ln(10)
Réponse : ln(10).

Exercice 4

Résoudre :

ln(x) > ln(7)
Correction :

La fonction ln est strictement croissante.

x > 7
Solution : ]7 ; +∞[.

Exercice 5

Calculer :

ln(1/e)
Correction :

ln(1/e) = −ln(e)

ln(1/e) = −1
Réponse : −1.

Exercice 6

Déterminer la dérivée de :

f(x) = ln(3x + 2)
Correction :

On utilise :

[ln(u)]' = u'/u

Avec :

u(x) = 3x + 2

Donc :

f'(x) = 3/(3x + 2)

Exercice 7

Étudier le sens de variation de :

f(x) = ln(x)
Correction :

Pour x > 0 :

f'(x) = 1/x > 0

La fonction est donc :

strictement croissante sur ]0 ; +∞[
